## 五、問題回答

### 問題一：為什麼「4」要先轉成數字，才能用於本題的分攤計算？

因為「4」如果放在引號裡，Python 會把它當成文字（字串），而不是數字。文字不能直接拿來做本題需要的數值除法，所以需要使用 `int()` 將文字「4」轉換成整數 4，才能用應付總額除以人數，計算每個人的分攤費用。

例如：

```python
people = "4"
people_num = int(people)
amount_per_person = 1220 / people_num
```

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？

如果先扣除 100 元折價券，再以剩餘餐費計算 10% 服務費：

1. 扣除折價券：1,200 - 100 = 1,100 元
2. 計算服務費：1,100 × 10% = 110 元
3. 應付總額：1,100 + 110 = 1,210 元

因此應付總額會變成 1,210 元。

這與題目規定的 1,220 元不同，是因為題目要求服務費以原始餐費 1,200 元計算，所以服務費是 120 元，再扣除折價券。兩種計算方式的順序不同，因此結果也不同。
